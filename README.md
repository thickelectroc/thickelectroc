# thickelectroc

### Learning AI. Exploring robotics.

I'm interested in how models learn, how robots perceive their surroundings, and how to connect predictions to useful actions.

This profile is a place for small experiments, study notes, and reproducible examples as I work through those topics.

## Learning direction

| Area | Questions to explore |
| --- | --- |
| Model training | How do data splits, baselines, and optimization affect the result? |
| Computer vision | How can a model turn images into useful measurements? |
| Robot control | How do feedback and simple controllers change motion? |
| Learning in simulation | When does a learned policy outperform a simple baseline? |

## Project roadmap

These are planned projects, not completed work:

- **Training lab** — train a small image classifier, compare it with a baseline, and document mistakes as well as metrics.
- **Robot control sandbox** — simulate a mobile robot and compare proportional and PID control on the same tasks.
- **Vision to action** — use a synthetic scene to explore how perception errors affect a controller.

## How I want to document experiments

- State the question before running the experiment.
- Keep the setup small enough to reproduce locally.
- Record the seed, configuration, and evaluation method.
- Include failure cases and limitations alongside results.

Starting with the fundamentals, one experiment at a time.
